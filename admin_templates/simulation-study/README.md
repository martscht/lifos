# Template - Simulation Study

Use this template if you do a simulation study. It includes a specific preregistration for simulation studies, a script folder with subfolders for simulation and validation scripts, a data folder for the simulated data, and a manuscript folder.

## Project structure

- 1_Preregistration
- 2_Scripts
    - Simulation_scripts
    - Validation_scripts
- 3_Data
- 4_Manuscript
- README.md

In **1_Preregistration**, you will find two files (a *.md* file and a *.tex* file), that all contain the same preregistration called **ADEMP_PreReg**, created by [Siepe et al. (2024)](https://pmc.ncbi.nlm.nih.gov/articles/PMC7616844/) ([GitHub Repository here](https://github.com/bsiepe/ADEMP-PreReg/tree/main)). If you want to fill out the preregistration in your Browser (Markdown Syntax), use the *.md* file. If you want to use LaTeX, you can either use the *.tex* file or fill out the preregistration [directly on Overleaf](https://www.overleaf.com/latex/templates/ademp-prereg-simulation-study-template/dkhtxjtmpbfj) and download the compiled PDF.

When you are done with the analyses of your dataset, you can upload the scripts (e.g., R scripts or JASP files) into the folder **2_Scripts**. In case you have several scripts of your simulation study, make use of the nested folder structure. For example, you could have one script for simulating data, which would then go into the folder **Simulation_scripts**, and you might have another script for testing and validating your analyses, this would then go into **Validation_scripts**. Feel free to adjust and adapt this folder structure to your study's needs. 

Do not forget to also upload your simulated (and if available also empirical data) to **3_Data**.

When you are ready with your manuscript (e.g., Bachelor or Master thesis), you can upload a final PDF version to **3_Manuscript**.

Last but not least, the **README.md** file is a Markdown text file that contains information about your project, including its purpose, contents, usage, and other details. It is usually located in the root directory. The README file serves as a quick reference for anyone trying to understand or use your project, and is an important resource for anyone who comes across it.
