# Template - PsyBSc2 Statistik I Praktikum

Verwendet dieses Template im PsyBSc2 Statistik I Praktikum, um ein Projekt für eure Gruppenarbeit anzulegen. Dabei wird automatisch die Standardordnerstruktur angelegt (d.h., Ordner für Präregistrierung, Materialien, Skripte, Daten, und Bericht) inklusive einer spezifischen Präregistrierungsvorlage für das Praktikum.

## Projektstruktur

- 1_Präregistrierung
- 2_Materialien
- 3_Skripte
- 4_Daten
- 5_Bericht
- README.md

In **1_Präregistrierung** liegt eine Vorlage (namens *PsyBsc2_preregistration.md*). Es handelt sich dabei um eine Markdown Datei, welche ihr direkt im Browser ausfüllen könnt. Um die Präregistierung auszufüllen, editiert die Datei mit einem Klick auf *Edit single file* über den *Edit* Button. Schickt anschließend eurem Dozenten einen Link zur Datei, um Feedback einzuholen.

Anschließend arbeitet ihr das Feedback ein und schließt somit eure Präregistrierung ab. Die Zeit, zu der die Datei das letzte mal editiert wurde, wird als Zeitstempel für die Präregistrierung verwendet.

In **2_Materialien** könnt ihr alle Materialien hochladen, die in eurer Studie verwendet wurden. In diesem Fall ist dies der Fragebogen, den eure Dozierenden mit euch teilen.

Wenn ihr mit der Datenanalyse fertig seid, könnt ihr euer R-Skript im Ordner **3_Skripte** hochladen. Achtet darauf, dass euer Ergebnisse auch auf anderen Rechnern reproduzierbar sind, sprich, dass euer Skript durchläuft und dieselben Ergebnisse ausgibt. Darüber hinaus sollte euer Skript auch für unbeteiligte Personen verständlich sein sollen. Achtet dafür auf eine sinnvolle Struktur, vergebt sinnvolle Variablennamen und kommentiert euer Skript. 

Dies gilt ebenso für das Datenset, welches in **4_Daten** hochgeladen werden soll.

Wenn ihr mit eurem Gruppenbericht fertig seid, ladet ihr die finale PDF-Version im Ordner **5_Bericht** hoch.

Zu guter Letzt, gibt es dann noch dieses **README.md**-Dokument, das ihr gerade lest. Das README ist eine Markdown-Textdatei, die Informationen über euer Projekt enthält, einschließlich seines Zwecks, Inhalts, seiner Verwendung und anderer Details. Sie befindet sich normalerweise im Stammverzeichnis. Die README-Datei dient als Schnellreferenz für jeden, der versucht, euer Projekt zu verstehen oder zu verwenden, und ist eine wichtige Ressource für jeden, der auf sie stößt.
