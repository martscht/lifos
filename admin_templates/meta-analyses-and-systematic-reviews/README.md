# Template - Meta-Analyses and Systematic Reviews

Use this template if you would like to initiate a folder with the subfolders (i.e., protocol, scripts, data, manuscript) including the [PROSPERO registration form](https://www.crd.york.ac.uk/prospero/) and the [PRISMA 2020](https://www.prisma-statement.org/) checklist protocol, as introduced by [Page et al. (2021)](https://doi.org/10.1136/bmj.n71).

## Project structure

- 1_Preregistration_and_PRISMA
- 2_Scripts
- 3_Data
- 4_Manuscript
- README.md

In **1_Preregistration_and_PRISMA**, you will two Markdown files called *PROSPERO_registration.md* and *PRISMA_2020_checklist.md*. [PROSPERO](https://www.crd.york.ac.uk/prospero/) stands for International **PROSPE**ctive **R**egister **O**f systematic reviews and is used as a preregistration platform for meta-analyses and systematic reviews. [PRISMA](https://www.prisma-statement.org) stands for **P**referred **R**eporting **I**tems for **S**ystematic Reviews and **M**eta-**A**nalyses and the checklist covers 27 items that are used to establish a standard in the reporting of systematic reviews and meta-analyses. For your project, first create a preregistration based on the PROSPERO registration form. Fill out the template before you start data collection. When your report is finished, fill out the PRISMA checklist template as well. Finally, also upload a PRISMA flow diagram of your literature selection. See [here](https://www.prisma-statement.org/prisma-2020-flow-diagram) for tools to create flow diagrams.  

When you are done with the analyses of your dataset, you can upload the scripts (e.g., R scripts or JASP files) into the folder **2_Scripts**. 

The same applies for the dataset, which can then be uploaded to **3_Data**.

When you are ready with your manuscript (e.g., Bachelor thesis), you can upload a final PDF version to **4_Manuscript**. You might consider uploading the original manuscript containing the study to be replicated as well. To be allowed to do so, the original manuscript must be published under open access. 

Last but not least, the **README.md** file is a Markdown text file that contains information about your project, including its purpose, contents, usage, and other details. It is usually located in the root directory. The README file serves as a quick reference for anyone trying to understand or use your project, and is an important resource for anyone who comes across it. In your README file, it is **especially important** to mention the original manuscript as a proper reference and linking to it. This should be done early on in the README file.
