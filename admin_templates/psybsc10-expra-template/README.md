# Template - PsyBSc10 - ExPra [replace this with your own title]

Use this template in the PsyBSc10 "Empirisch-experimentelles Praktikum" (ExPra) to create a folder for your small-group project. This folder contains the standard subfolders (i.e., preregistration, materials, scripts, data, manuscript) including the AsPredicted preregistration file.

## Project structure

- 1_Preregistration
- 2_Materials
- 3_Scripts
- 4_Data
- 5_Manuscript
- README.md

Please note that the preregistration, materials and data files (1, 2 and 4) are created collaboratively by your project group and only need to be uploaded once. However, we ask each student to create their own analysis scripts (3), and upload them into respective individual folders within the 3_Scripts folder (more information on this below).

In **1_Preregistration**, you will find a file *AsPredicted_preregistration.md* that covers the questions of a preregistration performed on [AsPredicted.org](https://aspredicted.org/) (see the variety of different formats [here](https://help.osf.io/article/229-select-a-registration-template)). The template provided is in Markdown format (.md), which allows your group to comfortably fill out the template in your webbrowser. See "Additional resources" for more information on Markdown.

To preregister your project, edit this template by choosing *Edit single file* or *Open in Web IDE* through the *Edit* button. Then, send the link to your ExPra supervisor for feedback. Finalize your preregistration based on the provided feedback.

In **2_Materials**, please upload all the materials that you have used to conduct your study. These could be, for example, stimuli, original questinnaires, or experimental scripts and files. 

When you are done with the analyses of your dataset, we ask you to upload the R script(s) containing code of all analyses you carried out in **3_Scripts**. Make sure that your results are reproducible on other computers, i.e. that your script runs and produces the same results. Furthermore, your script should also be understandable for other people. Make sure that your script has a meaningful structure, assign meaningful variable names and comment your script. 
Please note that this part of the upload should be done *individually*, i.e., we ask each student to upload their own, independently created script files as part of their final exam ("Prüfungsleistung"). To do so, please create a folder following the name pattern *"LastName_FirstName"* within the 3_Scripts folder, and upload your script files inside it. 

The collected data for your group project and a codebook for the data can be uploaded to **4_Data**. This should be one data file for the whole group. Please make sure the data is anonymized (i.e., it contains no sensitive personal information) before you upload the file, and that you are allowed to share it. If you are unsure, consult your supervisor.

After you have completed your manuscript and submitted it to your supervisor, you may upload a final PDF version to **5_Manuscript**. Please note that part is voluntary and if you wish, you can also anonymize your manuscript before uploading it to LIFOS. In the spirit of transparency, we would be very grateful if you would upload your final manuscript to LIFOS (anonymized or not), but as we said, you don't have to, this is voluntary. Doing so or not doing so will not affect your grade.

Last but not least, the **README.md** file is a Markdown text file that contains information about your project, including its purpose, contents, usage, and other details. It is usually located in the root directory. The README file serves as a quick reference for anyone trying to understand or use your project, and is an important resource for anyone who comes across it.
