# Template - Replication Study

Use this template if you would like to initiate a folder with the standard subfolders (i.e., preregistration, materials, scripts, data, manuscript) including the Replication Recipe preregistration file by [Brandt et. al (2013)](https://www.sciencedirect.com/science/article/pii/S0022103113001819).

## Project structure

- 1_Preregistration
- 2_Materials
- 3_Scripts
- 4_Data
- 5_Manuscript
- README.md

In **1_Preregistration**, you will find a file called *ReplicationRecipe_preregistration.md* that covers the questions of a preregistration specifically designed for replication studies ([Brandt et. al, 2013](https://www.sciencedirect.com/science/article/pii/S0022103113001819)). The template provided is in Markdown format (.md), which allows to comfortably fill out the template in your webbrowser. See "Additional resources" for more information on Markdown.

Edit this template by choosing *Edit single file* or *Open in Web IDE* through the *Edit* button. The time of your last edit will be taken as the timestamp.

In **1_Preregistration**, you will find a file *AsPredicted_preregistration.md* that covers the questions of a preregistration performed on [AsPredicted.org](https://aspredicted.org/) (see the variety of different formats [here](https://help.osf.io/article/229-select-a-registration-template)). 

In **2_Materials** you can upload all the materials that you have used to conduct your study. These could be, for example, questionnaired used, survey files, or experimental scripts. If you do not have such materials or are not allowed to share your materials, delete this folder. If you are unsure, consult with your supervisor.

When you are done with the analyses of your dataset, you can upload the scripts (e.g., R scripts or JASP files) into the folder **3_Scripts**. 

The same applies for the dataset, which can then be uploaded to **4_Data**.

When you are ready with your manuscript (e.g., Bachelor thesis), you can upload a final PDF version to **5_Manuscript**. You might consider uploading the original manuscript containing the study to be replicated as well. To be allowed to do so, the original manuscript must be published under open access. 

Last but not least, the **README.md** file is a Markdown text file that contains information about your project, including its purpose, contents, usage, and other details. It is usually located in the root directory. The README file serves as a quick reference for anyone trying to understand or use your project, and is an important resource for anyone who comes across it. In your README file, it is **especially important** to mention the **original manuscript** as a proper reference and linking to it. This should be done early on in the README file, so that readers know which study was replicated.
