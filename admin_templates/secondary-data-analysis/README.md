# Template - Secondary Data Analysis

Use this template if you do a study using already existing data. It includes a preregistration for secondary data analyses, a script folder, and a manuscript folder.

## Project structure

- 1_Preregistration
- 2_Scripts
- 3_Manuscript
- README.md

In **1_Preregistration**, you will find a file called *SecondaryDataAnalysis_preregistration.md* that covers the questions of a preregistration specifically design for secondary data analysis studies (see the variety of different formats [here](https://help.osf.io/article/229-select-a-registration-template) and [here](https://osf.io/zab38/wiki/home/)).

When you are done with the analyses of your dataset, you can upload the scripts (e.g., R scripts or JASP files) into the folder **2_Scripts**. 

When you are ready with your manuscript (e.g., Bachelor or Master thesis), you can upload a final PDF version to **3_Manuscript**.

Last but not least, the **README.md** file is a Markdown text file that contains information about your project, including its purpose, contents, usage, and other details. It is usually located in the root directory. The README file serves as a quick reference for anyone trying to understand or use your project, and is an important resource for anyone who comes across it.
