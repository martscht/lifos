## Current study: Variables

### Question title: Manipulated variables
**Option:** Not Applicable  
**Description:** Identify the manipulated variables planned for use. Describe the variables and levels or treatment arms. For observational studies and meta-analyses, state that it is not applicable. If groups are collapsed across variables, explicitly note and provide the formula.  
**Question type:** Open-ended  
**Example:** The percentage of sugar by mass added to brownies was manipulated in the original data collection. Four levels of this categorical variable were used: 15%, 20%, 25%, or 40% cane sugar by mass. This variable is not included in the present analyses.

### Question title: Measured variables
**Description:** Describe each variable that was measured, including outcome measures, predictors, or covariates used in confirmatory analyses. Unused variables from the dataset do not need to be described.  
**Question type:** Open-ended  
**Example:** The single outcome variable is the perceived tastiness of the single brownie each participant eats. This is measured with two items on a 1–7 scale.

### Question title: Scales
**Option:** Not Applicable  
**Description:** A scale is a measure of a construct that includes at least two items, aggregated into a smaller set of scores for modeling. If a scale is used, describe the construct it represents and the variables used to create it.  
**Question type:** Open-ended  
**Aggregation example options:** Mean score, Sum score, Weighted mean or weighted sum, EFA, SEM/CFA, Other (with details).  
**Question type (validation research):** Yes/No

### Question title: Index/Indices
**Option:** Not Applicable  
**Description:** An index is an indicator of a value or quantity. If creating or using an index, indicate which variables in the dataset are used, how they are aggregated, and what the aggregated measure represents. Note if the aggregation is based on codebook or validation research.  
**Question type:** Open-ended  
**Example:** The mean of the two questions about brownie tastiness is taken to create a single measure of “brownie enjoyment.”

### Question title: Transformations
**Description:** If transforming, centering, or recoding data (or using any coding scheme for categorical variables), describe the process.  
**Question type:** Dropdown menu

- Grand mean centering  
- Group mean centering  
- Standardizing  
- Log (log e)  
- Log (base 10)  
- Square-root transform  
- 1/x  
- Winsorizing  
- Other

### Question title: Data Inclusion/exclusion
**Description:** Which units of analysis are included or excluded (participants, cohorts, waves, etc.)?  
**Example:** All participants with complete data at Wave 1 are included, using data from Waves 1, 3, and 5.

### Question title: Outliers
**Option:** Not Applicable  
**Description:** Define what an outlier is and describe the plan for handling them.  
**Example:** Any data point outside the interquartile range is considered an outlier. If encountered, bootstrapping will be used to estimate parameters.

### Question title: Weights
**Option:** Not Applicable  
**Description:** If sampling weights are available, describe how they will be used.  
**Question type:** Open-ended  
**Example:** This data set provides sampling weights that mirror the national population. These are used to weight responses in the regression model.

### Question title: Sample size
**Description:** Provide the sample size. For each research question, what is the smallest effect size of interest? What power is expected for detecting that effect?  
**Question type:** Open-ended  
**Example:** The dataset includes 1,500 participants. After applying inclusion criteria, 1,200 remain. The smallest meaningful effect size is r = .10, and there is 80% power to detect this effect.

### Question title: Missing data
**Description:** Describe any known missing data (e.g., missingness rate, differential dropout). How will incomplete or missing data be addressed?  
**Example:** If a subject does not complete any of the three indices of tastiness, that subject will not be included in the analysis.

## Current study: Analyses

### Question title: Statistical models
**Description:** For each hypothesis, describe the statistical model. Include the model type (ANOVA, multiple regression, SEM, etc.), specification, predictors, outcomes, covariates, interactions, and planned post-hoc analyses. Any test not listed must be marked as exploratory.  
**Example:** A one-way between-subjects ANOVA will be used. The manipulated, categorical independent variable is “sugar,” and the dependent variable is the taste index.

### Question title: Follow-up analyses
**Description:** Specify any confirmatory follow-up analyses (e.g., subgroup analyses, pairwise or complex contrasts, interactions). Analyses not specified here must be reported as exploratory.  
**Example:** If the ANOVA indicates that mean taste perceptions differ significantly (p<.05), a Tukey-Kramer HSD test will be performed for all possible pairwise comparisons.

### Question title: Inference criteria
**Description:** Describe the criteria for making inferences (p-values, effect sizes, confidence intervals, Bayes factors, model fit indices) and any cutoffs or corrections. State if one- or two-tailed tests are used, and how multiple comparisons or hypotheses are accounted for.  
**Example:** p<.05 is used as the criterion for significance in the ANOVA and post hoc tests. A Tukey-Kramer test adjusts for multiple comparisons.

### Question title: Sensitivity Analyses
**Option:** Not Applicable  
**Description:** Provide decisions about evaluating the strength, reliability, or robustness of the focal hypothesis test (e.g., control variables, cross-validation, machine learning, weights, constraints in SEM).  
**Question type:** Open-ended  
**Example A:** The data will be split into two random halves. Primary analyses will be run in the first sample and reproduced in the second to confirm results.  
**Example B:** Two models will be run, one with covariates and one without. Both sets of results will be reported.

### Question title: Statistical Analysis Backup Plan
**Option:** Not Applicable  
**Description:** Describe the plan if data violate assumptions, the model does not converge, or other analytic issues arise.  
**Example:** If the multilevel model with random variables A, B, and C predicting Y using X fails to converge, smaller models will be utilized by removing random variables with near-zero variance.

### Question title: Exploratory analysis
**Description:** If there are plans to explore the dataset for unexpected differences or relationships, describe them here (tests where a prediction is not made up front, or multiple possible tests could be used). A significant finding in an exploratory test may inspire a new confirmatory hypothesis and a subsequent registration.  
**Example:** Demographic traits such as age, gender, income, and marital status will be examined to see if they relate to the primary outcome measures of taste preferences.
